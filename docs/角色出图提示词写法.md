## 1. 先选模型，语法不要混用

同一套画面结构可以共用，但参数写法必须按模型分开。下面三类不要写在同一条提示词里。

| 模型 | 怎么写约束 | 不要混入 |
| --- | --- | --- |
| **Midjourney / Niji** | 正文用逗号或自然语言描述，参数放在末尾：`--ar 3:4 --stylize 100 --v 6`。排除用 `--no extra fingers, text, watermark`。强调用 `词::2`（仓库 Keyword Weight 对照页的写法是 `A::# B::#`）。 | 不要写 `(hand:1.4)`，也不要另起一行 `Negative prompt:`。`--no` 不是 SD 的负面提示词。 |
| **Stable Diffusion / SDXL** | 强调用 `(word:1.2)`，减弱用 `(word:0.7)`。负面词必须单独放在 **Negative prompt** 里。 | 不要写 `--ar`、`--stylize`、`--v`、`--no`。画幅用界面里的宽高，不要把 MJ 参数贴进正词。 |
| **Flux / GPT Image / DALL·E / Nano Banana Pro** | 用完整自然语言写清要什么、不要什么。Cookbook 的 `style.json` 就是给这类「能读长结构化提示词」的端到端模型用的（仓库推荐 ChatGPT Images 2、Nano Banana Pro）。 | 不要把 `--ar 16:9` 或 `(plastic:1.3)` 塞进自然语言段。画幅写成 “Create a 3:4 image”，禁止项写成 “Do not include…”。 |

Midjourney 仓库里和写法直接相关的对照结论（来自 V4 对照页原文，不是后补口诀）：

- **词序会改画面**：`Sphere Galaxy` 和 `Galaxy Sphere` 结果不同。重要主体放前面。
- **连接方式会改关系**：空格并列、逗号并列、`::`、分号、`in the style of`、`made of`、`of a`、括号，效果不一样。锁材质用 `made of vinyl and plush`；锁画风用 `in the style of flat design`；不要随手把所有词都用逗号连上。
- **`--stylize`**：让画面更 stylized。V4 对照从 `--stylize 0` 到 `--stylize 1000`。角色设定图、三视图要可控时用低到中（如 50–150）；要更炫的宣传图再升高。
- **`--quality`**：控制「花多久生成」，对照值为 `--quality 0.25 / 0.5 / 1`，不是「写成 8k 就会更清晰」。清晰度词（`4k`、`8k`）是 Digital 页里的风格词，和这个参数不是一回事。
- **`--chaos`**：增加随机性，原文写 “in practice, it seems to make them more stylized”。锁同一只角色时用 `0` 或很低。
- **`--no`**：阻止特定元素。可叠写 `--no red --no pink`，也可以 `--no red, pink`。角色出图常用来排除：`extra fingers, extra limbs, text, watermark, realistic human skin`。

## 2. 通用提示词结构（先填这一段）

无论哪个模型，都按下面 12 槽位写。先锁「角色 + 造型 + 画风」，再改姿势、景别和场景。Cookbook 的做法是：风格锚点固定，只替换变量；角色出图同理——**角色锚点固定，只替换镜头和场景**。

```text
【主体】谁：物种 / 名字 / 体型 / 年龄感 / 是吉祥物还是真人
【造型】头身比、脸、眼睛、标志特征（每次原样粘贴）
【姿势】站、坐、走、挥手；设定图要写 “neutral standing pose, arms slightly away from body”
【服饰与配色】衣服、配饰、固定色板（写颜色名，最好补十六进制）
【景别 / 构图】特写、胸像、半身、全身、三视图、表情表；是否居中、留白、白底
【镜头】焦距、机位、透视（见第 5 节词表）
【光线】棚灯、阳光、 rim light 等
【材质】乙烯、毛绒、针织、毡、塑料等，写到能摸到的程度
【风格】2D 平涂 / 3D 潮玩 / 扁平面 / 产品海报；只选一种，不要同时写互斥风格
【画幅】3:4 设定图、16:9 场景、1:1 头像、3:2 或 16:9 三视图/表情表
【质量】模型对应的质量写法（见下）
【禁止项】手、多余手指、脸漂、水印、现有 IP、真实品牌、混风格
```

### 2.1 角色锚点（每次原样粘贴，不要改）

下面是示例角色「盐仔」的锁定段。换自己的 IP 时，只改这一段，后面所有模板都继续引用它。

```text
一只原创海边潮玩吉祥物「盐仔」：圆滚滚的海鸥雏鸟体型，头身比约 1:2，奶油色哑光乙烯脸，盐白色密绒身体（可见短纤维），珊瑚橙毡喙，巨大光泽眼睛，每只眼睛里只有一颗清晰的四点星形高光。穿芥末黄连帽风衣，戴青绿针织围巾（可见织纹），背后一个迷你红白救生圈背包，胸口有小小浪花刺绣。短翼像连指手套，粗短腿，剪影圆润清晰，五官极简、高度可读。不是真人，不是现有商业 IP。
固定色板：奶油 #F6EAD2，盐白 #F8F4E7，珊瑚橙 #E26A4A，芥末黄 #E2B23A，青绿 #2BAEC6，救生圈红 #E0263C。
```

英文锁定段（投 Midjourney / Flux / 英文模型时用）：

```text
An original seaside trendy-toy IP mascot named Yanzi: a chubby seagull chick, about 1:2 head-to-body ratio, matte cream vinyl face, salt-white dense plush body with visible short fibres, coral-orange felt beak, huge glossy eyes each with exactly one crisp four-point star highlight. Wearing a mustard-yellow hooded windbreaker, a teal knit scarf with readable weave, and a tiny red-and-white life-ring backpack; a small wave embroidery on the chest. Mitten-like short wings, stubby legs, round highly readable silhouette, minimal facial features. Not a human, not an existing commercial IP.
Fixed palette: cream #F6EAD2, salt-white #F8F4E7, coral-orange #E26A4A, mustard #E2B23A, teal #2BAEC6, life-ring red #E0263C.
```

### 2.2 质量槽怎么填（按模型）

- **Midjourney**：参数用 `--quality 1 --stylize 100 --chaos 0`（设定图）；宣传图可把 `--stylize` 提高到 250–500。正文里可加仓库 Digital / Camera 页的词：`3D render, product photography, sharp focus`。不要既写 `--quality 1` 又堆一长串无关的 `16k 32k masterpiece`。
- **Stable Diffusion**：正词可写 `sharp focus, clean design, highly readable silhouette`；手和脸的问题放进 Negative prompt，不要在正词里反复堆 `8k 16k`。
- **Flux / GPT Image**：写成完整句子，例如 “premium stylized 3D toy-mascot render, sharp readable details, no watermark”。Cookbook 推荐把整个 `style.json` 喂给模型，而不是只摘一句风格形容词。

## 3. 用 Cookbook 锁定画风

Cookbook 的核心不是「再写一句 in the style of」，而是把一种视觉系统拆成可复用的 `style.json`：**锚点固定，只换变量**。

### 3.1 锁风格的可复用方法

从 `style.json` 字段和 `CONTRIBUTING.md` / 中文 README 里抽出这 7 步，角色出图直接套：

1. **先定风格锚点 `style_fidelity_anchors`**  
   把必须每次出现的东西写成 6–12 条：渲染方式、材质、色板、线宽、镜头、构图层级。标成 CORE 的不要改；FLEX 的（物种、动作、标题位置）才按张替换。

2. **只替换 `environment_variables`**  
   常见变量：`SUBJECT`、`SUBJECT_ACTION`、`PRODUCT_OR_PROP`、`LOCATION`、`BACKGROUND_ELEMENTS`、`WARDROBE_STYLE`、`MAIN_TEXT`、`ASPECT_RATIO`。角色锚点相当于你自己加的一个不可变 `SUBJECT` 描述。

3. **固定色板 `color_palette`**  
   写准主色、点缀色和「哪些颜色必须同时出现」。例如 Cobalt Pals 要求钴蓝、白、黑、蛋黄、泡泡糖粉五色每张都可见。

4. **写清 `source_content_to_avoid`**  
   这不是普通负面词，而是「不要抄原参考的角色、文案、构图故事」。换主题时必须换主体、道具、文字，但保住锚点。

5. **用 `design_rules` / `do` / `avoid` 管构图纪律**  
   例如 Soft Giants 明确禁止「中性站立吉祥物」；做设定图就不要用这个风格，另选中性棚拍模板。

6. **画幅原生生成，不要裁切**  
   多个风格都写：9:16 和 16:9 要按同一角色和标题重新构图，禁止从竖图裁出横图。

7. **有字就要「逐字核对准」**  
   标题写进 `MAIN_TEXT`，模板里要求 spelled letter by letter。角色设定图建议 **画面内不要字**，把名字放在提示词里而不是印在图上。

把完整 JSON 放进 GPT Image / Nano Banana Pro / Claude 图像工作流，改 `examples[*].values` 或按变量表填值即可。本指南已复制 5 个角色向原件到 `styles/`，用法见第 7 节。

### 3.2 五份真实风格：各适合什么图

#### A. Soft Giants（`styles/soft-giants/`）

- **类型**：Type Posters；3D 潮玩巨型海报。
- **锁定了什么**：哑光乙烯脸 + 密绒可见纤维 + 缝制毡/针织衣；眼睛里固定一颗四点星高光；16mm 广角、近大远小；角色必须和画框或重力玩（探头、倒挂、俯视小世界），禁止中性站姿；酸青柠色模糊喷边大标题；暖阳轮廊光、彩虹漏光、漂浮粒子。
- **适合**：潮玩 IP 宣传大片、主视觉、要「可爱但有尺度反差」的海报。
- **不适合**：三视图、表情表、白底设定图（它自己的 avoid / negative 写了 “neutral standing pose”）。

#### B. Cobalt Pals（`styles/cobalt-pals/`）

- **类型**：Type Posters；平面活动海报。
- **锁定了什么**：整张钴蓝平涂底，无渐变、无照片、无 3D；白色团块动物、均匀偏抖的粗黑马克笔轮廓、纯平涂、无阴影；角色巨大、大斜线、至少一边被裁切；固定五色（钴蓝 #1466D8、白、黑、蛋黄 #FFE100、泡泡糖粉 #F26BB5）；手绘大标题每张换一种字体，但色和线宽不变。
- **适合**：高识别度的 2D IP 主视觉、活动海报、贴纸感物料。剪影极清楚，适合做品牌识别。
- **不适合**：写实棚拍、需要立体毛绒质感的产品特写、中性站立设定图。

#### C. Sunny 3D Avatar Campaign Style（`styles/sunny-3d-avatar-campaign-style/`）

- **类型**：Product + Campaign；晴天户外 3D 头像海报。
- **锁定了什么**：光滑玩偶感 3D 头像、圆手、软塑料皮肤、简化表情眼；烈日高饱和蓝天绿地；广角近景裁切；倾斜的巨大白色标题 + 霓虹绿/青手绘运动线；分层：天空标题 / 前景角色 / 中景活动 / 底部活动标。
- **适合**：社交投放、活动预热、角色在真实户外场景里的宣传图。
- **不适合**：扁平矢量、赛璐璐动漫、写实真人、阴天脏纹理、角色设定白底图。

#### D. Plush Comic Toy Product Poster Style（`styles/plush-comic-toy-product-poster-style/`）

- **类型**：Product + Campaign；毛绒玩具产品海报。
- **锁定了什么**：一只毛绒英雄产品，奶油纸底 + 青绿大圆背景；3/4 侧、软棚影；倾斜漫画块面标题（柠檬黄 + 信号红 + 厚黑投影）；平面印刷图形叠在立体毛绒上；涂鸦箭头、闪电贴、贴纸标。
- **适合**：潮玩产品主图、周边上市海报、要「摸得到毛」的商品感，同时保留漫画标题冲击力。
- **不适合**：极简奢侈品广告、没有绒毛的光滑塑料、真实车广、黑暗恐怖风、密密麻麻大段文字。

#### E. Bold Block Mascot Poster Style（`styles/bold-block-mascot-poster-style/`）

- **类型**：Type Posters；粗块面吉祥物海报。
- **锁定了什么**：巨型黑体标题占结构；一两只圆滚白吉祥物、极粗黑线、五官极少；一块倾斜的青/薄荷色大色板；高密度但全是平涂；米白印刷纸感，轻微网印压缩，不是光泽广告；点缀一小块红。
- **适合**：要高度可读、像贴纸/网印/社交海报的 IP 形象，信息图和主视觉都可以。
- **不适合**：写实 3D、精细绘画、复杂背景、咖啡/课程/品牌标志这类源内容（该风格的 source_content_to_avoid 明确排除了这些）。

### 4.2 全身站立设定图（full-body standing）

用途：锁全身比例、服装和剪影。双臂略离开身体，五指/翼端可见，脚完整，不裁顶不裁脚。

#### 模板 · Midjourney


若已经用某份 Cookbook JSON 出过主视觉，换场景时：**整份 JSON 不要改，只改 `SUBJECT_ACTION`、`LOCATION`、`BACKGROUND_ELEMENTS`、`PRODUCT_OR_PROP`、`MAIN_TEXT`**。不要为了新场景另写一套色板或渲染方式。

## 5. 常用角色关键词短表

词条提炼自 MidJourney Styles 仓库 V4 Just The Style 各页的表格标题（Camera、Perspective、Lighting、Materials、Material_Properties、Design_Styles、Drawing_and_Art_Mediums、Digital、Themes、Dimensionality、SFX_and_Shaders、Intangibles）。仓库本身是「一词一图」对照，没有给每词写定义；下面的效果说明是按词义和这些分类整理的实用注释，便于选词，不是官方释义。每类 8–15 个，只留角色出图常用项。

投 Midjourney 时可直接把英文词放进提示词；投 SD 时同样可用这些英文词，需要强调再加 `(word:1.2)`；投 Flux / GPT Image 时把词写成句子，不要堆一排无语法标签。

### 5.1 景别 / 构图（Camera + Perspective + prompt-library 构图分类）

| 英文词 | 作用（一行） |
| --- | --- |
| Extreme Closeup | 大特写，只剩眼睛或喙，适合材质细节，不适合锁全身。 |
| Closeup / Closeup-View | 近景特写，脸和头饰为主。 |
| Portrait / Portraiture | 胸像级人像，肩膀以上，设定卡头图常用。 |
| Full Body Portrait | 全身像，务必再写 feet fully visible，否则容易裁脚。 |
| Wide Shot / Epic Wide Shot | 远景，角色变小、环境变大，适合场景海报，不适合第一次定妆。 |
| Establishing Shot | 建场镜头，先交代地点，角色不必占满画面。 |
| Centered-Shot | 居中，设定图、产品像更稳。 |
| Profile | 正侧脸/正侧身，三视图侧面用这个。 |
| Product-View | 产品展示视角，潮玩主图比「剧情镜头」更干净。 |
| Selfie / First-Person View | 第一人称或自拍感，宣传互动可以用，设定图不要用。 |
| Rule of Thirds | 三分法，场景图比白底设定图更需要。 |
| Closed Composition | 封闭构图，主体收在画面内，适合海报。 |

### 5.2 镜头 / 机位（Camera + Perspective）

| 英文词 | 作用（一行） |
| --- | --- |
| 35mm Lens | 接近人眼的标准焦距，设定图和普通全身像首选。 |
| 85mm Lens | 中长焦，胸像更压缩、更像人像摄影。 |
| Macro / Macro View | 微距，看绒毛和缝线；不要拿来拍全身。 |
| Wide Angle / Ultra-Wide Angle | 广角，空间被撑开，近处夸张。 |
| 15mm Lens / Fisheye Lens | 极广或鱼眼，Soft Giants / Sunny Avatar 类宣传图才用；三视图禁用。 |
| Telephoto | 长焦压缩前后景，环境肖像感。 |
| Low Angle | 仰拍，角色显得大、有气势。 |
| High Angle / Top-View / Aerial View | 俯拍或顶视，能交代队形和场景，脸会变小。 |
| Worms-Eye View | 极低仰视，巨人感，和 Soft Giants 的「近处巨大」一致。 |
| Orthographic / Multiview Projection | 正交/多视图，三视图必写，去掉透视变形。 |
| Isometric / Axonometric | 轴测/等轴测，偏设计展示，不是写实相机。 |
| Depth of Field / Shallow Focus / Bokeh | 浅景深虚化背景，宣传图好用；设定图改 Deep Focus，避免脸发糊。 |
| Soft-Focus | 柔焦，氛围感强，但会损「高度可读」。 |
| Lens Flare / Vignette | 镜头光斑和暗角，气氛配件，设定图应 `--no` 掉。 |

### 5.3 光线（Lighting）

| 英文词 | 作用（一行） |
| --- | --- |
| Studio Lighting | 棚灯，均匀可控，设定图、产品像首选。 |
| Soft Lighting | 软光，过渡干净，毛绒边缘更舒服。 |
| Hard Lighting | 硬光，阴影锐利，块面海报或强日光才用。 |
| Frontlight | 顺光，脸部信息最全，表情表好用。 |
| Backlight / Rim Lighting / Rim Lights | 逆光或轮廊光，把毛边和剪影从背景里勾出来。 |
| Natural Lighting / Sunlight / Direct Sunlight | 自然光或直射阳光，户外场景真实，注意别把脸曝掉。 |
| Golden Hour / Blue Hour | 金色黄昏或蓝调时刻，换场景时用来改时间，不改角色。 |
| High-Key Lighting | 高调，亮、少阴影，适合干净 IP 形象。 |
| Low-Key Lighting | 低调，暗、阴影多，情绪强，吉祥物主识别一般不用。 |
| Cinematic Lighting / Moody Lighting | 电影感/情绪光，宣传片可以，设定稿容易风格漂移。 |
| Accent Lighting | 局部强调光，打在关键道具（如救生圈）上。 |
| Volumetric Lighting / Godrays / Sunbeams | 体积光或耶稣光，空气感强，容易抢戏。 |
| Global Illumination | 全局照明，3D 渲染更自然，适合潮玩渲染词组。 |
| Candlelight / Practical 氛围灯 | 暖点光源，夜市场景可用；不要和棚拍设定图混用。 |

### 5.4 材质（Materials + Material_Properties）

| 英文词 | 作用（一行） |
| --- | --- |
| Vinyl / Polyvinyl | 乙烯玩具表面，潮玩脸和关节常用，偏光滑但可写成 matte vinyl。 |
| Plastic | 塑料感，更工业；要「潮玩」可与 vinyl 连用，避免变成廉价硬胶。 |
| Plush / Fur / Furry | 毛绒，最好再写 visible fibres，否则容易塑成光滑壳。 |
| Felt / Felt Cloth | 毡，适合喙、补丁、扁平玩具零件。 |
| Knitted / Cotton / Velvet / Satin | 针织、棉、丝绒、缎：衣服织纹；针织围巾要写 readable weave。 |
| Rubber / Silicone | 橡胶或硅胶，更软弹，适合玩具手感，不像硬塑料。 |
| Clay / Terracotta / Ceramic | 黏土、陶土、陶瓷，偏手作或公仔，不是毛绒潮玩。 |
| Matte | 哑光，降低油亮，IP 脸更稳、更好看。 |
| Glossy / Shiny / Specular Highlights | 高光和反光，眼睛、潮湿表面可用；不要整身都 glossy。 |
| Translucent / Subsurface-Scattering | 半透明和次表面散射，耳尖、指尖透光（Soft Giants 锚点就有这个）。 |
| Soft / Squishy / Soft Body / Blobby | 软、可挤压、团块感，强化吉祥物体型。 |
| Stitched / Sewing / Embroidered（可与 stitched felt 连用） | 缝线、刺绣，让玩具像能缝出来的，而不是裸模。 |

### 5.5 画风（Design_Styles + Themes + Drawing_and_Art_Mediums + Digital + Dimensionality + SFX）

| 英文词 | 作用（一行） |
| --- | --- |
| Stylized | 总的「风格化」开关，比 realistic 更适合 IP。 |
| 3D / 3D Render / Cinema4D / C4D / Octane / Blender Render | 指向三维渲染器审美，潮玩主形象常用；一次只留 1–2 个引擎词。 |
| 2D / Flat / Flat Design / Flat Shading | 平面/平涂，走 Cobalt Pals 或 Bold Block 路线时用，不要和 Octane 同句。 |
| 2.5D | 介于 2D 与 3D 之间的厚涂或半立体，偏设定插画。 |
| Product Photography | 产品摄影感，白底或棚拍潮玩更像可售商品。 |
| Claymation / Stop Motion | 黏土动画或定格，另一种玩具感，和乙烯潮玩不是同一套。 |
| Cartoon / Kawaii / Anime / Manga | 卡通、可爱、动漫、漫画；IP 若要「高度可读潮玩」，不要同时堆 anime 和 Octane。 |
| Pop-Art / Memphis Design / Bauhaus Style | 强图形、色块、设计运动风格，海报系统可用。 |
| Ligne Claire / Ukiyo-e / Storybook Illustration | 清晰线描、浮世绘、绘本插画，偏 2D 叙事，不是 3D 产品像。 |
| Cel Shading | 赛璐璐分层上色，动漫感明确；Sunny 3D Avatar 的 avoid 里排除了它。 |
| Line Art / Doodle / Marker Art / Risograph / Sticker | 线稿、涂鸦、马克笔、孔版、贴纸，适合平面物料和活动海报。 |
| Minimalist / Hyperdetailed | 极简 vs 超细：吉祥物识别优先选干净剪影，细节点到材质即可，不要无节制 hyperdetailed。 |

### 5.6 质量与完成度（Digital + Camera + Design_Styles + SFX）

| 英文词 | 作用（一行） |
| --- | --- |
| Sharp / Sharpened / Sharp focus | 边缘清楚，设定图和表情表优先。 |
| 4k / 8k / UHD / Super-Resolution | Digital 页里的分辨率风格词，有一点「更精细」的倾向；它代替不了 MJ 的 `--quality`。 |
| HD / Full-HD | 同样是清晰度风格词，效力通常弱于具体的材质和镜头描述。 |
| Precision Rendering / Physically Based Rendering | 强调渲染精度或 PBR，3D 潮玩可用。 |
| Award Winning Photography | Camera 页词，偏摄影精品感；角色 IP 用得少，容易把画风拉向写实。 |
| Clean design / highly readable silhouette（自然语言，推荐） | 直接要求「干净、剪影可读」，比空泛的 masterpiece 对 IP 更有效。 |
| Anti-Aliasing / De-Noise / Digitally Enhanced / Post-Processing | 去锯齿、降噪、后期感；可轻度使用，写太多会变成滤镜堆砌。 |
| Film Grain | 细胶片颗粒，Soft Giants 锚点里有；干净电商白底则应排除。 |
| Cute / Whimsical / Playful Atmosphere | Intangibles / Themes 里的气质词，能把「玩具」往可爱推，但锁不住结构。 |
| --quality 1（仅 Midjourney 参数） | 仓库原文：控制生成花费的时间。设定图用 1；不要把它写进 SD 或 Flux。 |

## 6. 常见失败与修正

| 问题 | 常见原因 | 怎么改 |
| --- | --- | --- |
| 手/翼崩坏、多余手指 | 没写清「连指翼」或「手离开身体」；或在 MJ 里误用了 SD 的 `(hand:1.5)` | 设定图写 `arms slightly away from the body, mitten-like wings, no extra fingers`。MJ 用 `--no extra fingers, extra limbs`；SD 把这些放进 Negative prompt，不要把 `--no` 贴进 SD。 |
| 脸漂移、换场面孔不像 | 只写了「同一只角色」，没有重复锚点；或同时换了光线、风格和服装 | 每次完整粘贴角色锚点。换场景只改地点和动作。表情表写明 “only the expression changes”。能图生图时，用已通过的设定图作参考，而不是只靠文字。 |
| 多手指、多眼睛、多腿 | 广角/鱼眼把肢体拆碎；或 grid 表情表/三视图合成失败 | 设定类禁用 `Fisheye`、`16mm`。三视图、表情表写 `same scale`、`do not merge bodies/faces`，失败就拆成单张再拼。SD 加重 `(same character:1.4)` 并负面排除 `mutated hands, extra eyes`。 |
| 画风不稳定、忽 2D 忽 3D | 一句里同时写了 `Octane, anime, flat design, watercolor` | 一条提示词只保留一个渲染体系。3D 潮玩：`stylized 3D toy-mascot render, vinyl, plush, Octane`。2D IP：`flat 2D cartoon, thick black outline, pure flat fills, no shading`。把互斥项写进禁止里。 |
| 语法混用导致模型不理部分词 | 在 MJ 写 `Negative prompt:` 和 `(word:1.2)`；在 SD 写 `--ar 3:4 --v 6`；在 Flux 末尾加 `--stylize 200` | 按第 1 节重写。画幅：MJ 用 `--ar`，SD 用界面宽高，Flux/GPT Image 用 “Create a 3:4 image”。排除项：MJ 用 `--no`，SD 用 Negative prompt，自然语言模型用 “Do not include…”。 |
| 想锁风格却越写越散 | 每张图重写全部形容词，色板和镜头也不固定 | 用第 3 节的锚点法：固定材质、色板、线宽、渲染模式；只换 `SUBJECT_ACTION` 和 `LOCATION`。直接加载 `styles/` 里的 JSON，不要从记忆里改写色值。 |
| 三视图变成三只不同的鸟 | 模型把「三视图」理解成「三个角色」；或画幅太方导致挤压 | 用 16:9，写 `one character, three views, same scale, same costume`。明确左右顺序。仍失败就分三次生成正面/侧面/背面，保持同一套锚点和种子（MJ 可再加 `--chaos 0`）。 |
| 裁头、裁脚、只出胸像 | 写了 portrait 却想要全身；或 stylize / 广角过强 | 明确 `full body portrait, feet fully visible, margin above the head`，并 `--no cropped feet, cropped head, closeup`。设定图 `--stylize` 降到 50–80。 |
| 画面里出现乱字、水印、假 logo | 宣传风格（Soft Giants、Sunny Avatar、Plush Comic）默认会要标题 | 设定图、三视图、表情表一律禁止文字。海报类把标题写死在 `MAIN_TEXT`，并要求 spelled letter by letter；不要让模型自己编品牌名。 |
| 毛绒变成光滑塑料，或反之 | 材质词太少，或和互斥风格混用 | 毛绒：`dense plush, visible fibres, stitched, matte`。乙烯脸：`matte vinyl face` 和毛身分开写。不要在 Cobalt Pals 这类平涂风格里写 plush fibres。 |
| 吉祥物看起来像真人儿童或现有 IP | 缺 “not a human / not an existing commercial IP”，或风格锚点不够 | 锚点写物种和玩具材质。禁止项加上 `photoreal human, realistic child, existing IP characters`。Cookbook 的 negative / source_content_to_avoid 也是同一思路，可一并抄到禁止项。 |
| Midjourney 词权重不明显 | `::` 加在整段长句后面，或和 SD 权重混写 | 按仓库写法把**短词**加权：`vinyl::1.5 plush::1.5`。不要写成 `(vinyl:1.5)`。重要主体放最前面，因为词序本身就会改画面。 |

一条总的减法原则（prompt-library 的联动纪律也是这个意思）：某一部位反复崩时，先删互斥词和过高 stylize，而不是继续往上堆词。

## 7. 附带的 style.json 怎么用

本目录已复制 5 个原件（未改内容）：

- `styles/soft-giants/style.json`
- `styles/cobalt-pals/style.json`
- `styles/sunny-3d-avatar-campaign-style/style.json`
- `styles/plush-comic-toy-product-poster-style/style.json`
- `styles/bold-block-mascot-poster-style/style.json`

推荐工作流（来自 Cookbook 中文 README 的「快速开始」）：

1. 按第 3.2 节选一个风格，打开对应 `style.json`。
2. 把**完整 JSON** 放进 ChatGPT Images、Nano Banana Pro 或其他能读长 JSON 的图像模型（不要只复制一句话 summary）。
3. 在 `examples` 里新增一个 case，或直接改变量：把 `SUBJECT` 换成盐仔（或你的角色锚点），再填动作、场景、标题。
4. 不要改 `style_fidelity_anchors`、`color_palette`、`design_rules`。画幅按 JSON 说明选 9:16 或 16:9，让模型原生构图。
5. 这些 JSON 是海报系统，不是设定稿系统。白底三视图和表情表请用第 4.1–4.4 节模板，不要硬套 Soft Giants。
