# 儿童绘本画风

一本儿童绘本或一组闪卡只锁一种画风。不要只在第一页写一句 `in the style of`，后面各页另起一套材质和色板。正确做法是：先选定一张风格卡，把必须每次出现的部分写成 CORE 锚点，之后每页原样粘贴，只替换动作、表情和场景里的 FLEX 部分。

详细风格卡见 [references/styles.md](references/styles.md)。若还要写故事、分页、拼音和儿童安全检查，改用同仓库的 `children-picture-book`。本目录里的配方服务于儿童绘本和闪卡，不要把同仓库 `image-style-lock` 里的潮玩海报 JSON 硬套到低龄内页上。

## 1. 先选一张卡，再写锚点

根据年龄、内容和用途选风，不要先堆许多形容词。

- 认物、识字、数数、闪卡：优先选轮廓清楚、背景干净的平涂、简形或剪纸。
- 睡前、家庭、情绪陪伴：优先选水彩、彩铅或温暖手绘。
- 节日与民俗启蒙：可选年画、中国剪纸或皮影彩染；不要和水彩厚涂混用。
- 角色校准页或人物特写：可选暖光童画、墨线绘本或北欧绘本水粉。
- 低龄页避免过多梦幻光斑、浓雾和碎细节，以免主体看不清。

选定后打开 [references/styles.md](references/styles.md)，抄下该卡的 CORE、色板、材质和禁止项。一本书不要做「画风合集」。气氛向的梦幻或童话手法如果要用，也只能作为同一材料体系里的轻度变化，不能另换一套画材。

## 2. 区分 CORE 和 FLEX

把风格写成 6–12 条锚点，并标明哪些不能改：

- **CORE（每页原样保留）**：渲染方式与画材、纸面或媒介、线的有无与线宽、色板、光线，以及该风格特有的人物比例或五官画法。
- **FLEX（按页替换）**：动作、表情、镜头远近、场景里的临时道具、是留白页还是满版场景页。角色身份特征不属于 FLEX；那是角色圣经里的固定项。

还要写清「不要画成什么」，避免模型滑向相邻风格。例如：北欧绘本水粉不要画成大眼暖光概念稿；中国剪纸不要画成立体纸雕；儿童涂鸦风不要画成精修商业蜡笔滤镜。

换主题时必须换主体、动作和临时道具，但保住 CORE。不要为了某一张「更好看」的图，把全书线稿或色板改掉。

## 3. 每页都重复风格段，只改变量

出每一页时，提示词里都要出现完整的风格 CORE 和角色锚点。不要写「风格同上」。允许轮换满版、留白、特写和回声页，但材质、色板和人物比例必须同一套。画幅按页的用途选，并原生生成，不要从竖图裁出横图。

如果前两页已经不像同一套画，先收紧风格词、减少新道具，再继续后面的页。

## 4. 按模型改写，语法不要混用

风格卡里的材料描述可以共用，参数写法必须按模型分开。词序会改画面：角色和本页动作在前，风格和材质随后。

| 模型 | 怎么写约束 | 不要混入 |
| --- | --- | --- |
| Midjourney / Niji | 把 CORE 改成短词和材料短语，参数放末尾，例如 `--ar 3:4 --stylize 80 --v 6`。排除用 `--no 3D render, photorealistic, text, watermark`，并可补上该风格的互斥项。 | 不要写 `(gouache:1.3)`，也不要另起 `Negative prompt:`。 |
| Stable Diffusion / SDXL | 对关键画材用 `(watercolor wash:1.2)` 这类权重。负面词单独放在 Negative prompt，写入互斥画材和通用禁止项。画幅用界面宽高。 | 不要写 `--ar`、`--stylize`、`--v`、`--no`。 |
| Flux / GPT Image / DALL·E / Nano Banana Pro | 用完整句子写清画材、纸面、色板、光线和「不要画成什么」。画幅写成 “Create a 3:4 image”。 | 不要把 `--ar 16:9` 或 `(word:1.2)` 塞进自然语言段。 |

上游某些配方在特定模型上是用英文原文验证的。投英文模型时，可用风格卡里的英文关键词短句；不要把 Midjourney 参数贴进自然语言模型，也不要为了「更像原文」去混写两套语法。

## 5. 输出要求

- 先说明选了哪张风格卡、为什么适合当前年龄和用途，以及它不适合什么。
- 列出 CORE / FLEX / 色板 / 禁止项，再按用户指定的模型给出完整、可复制的提示词。多组提示词各自写全。
- 不要在提示词里点名要求模仿受版权保护的角色、在世画家的个人风格，或未授权的动画工作室设定。只描述材料、色板、构图和气质。
- 不要把真实公司地址、密钥或未公开项目名写进提示词。
