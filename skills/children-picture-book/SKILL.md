# 儿童启蒙绘本

把一课、一个生活主题或一个具体场景，做成适龄的插画绘本方案：先定年龄和学习目标，再写故事分页与角色圣经，然后按页写出图提示词，最后做儿童安全与图文质检。需要把画风跨页锁住时，改用同仓库的 `children-illustration-styles`。

细节模板和检查表见：

- 年龄、页数与学习材料：[references/age-and-materials.md](references/age-and-materials.md)
- 故事骨架与分页：[references/story-structure.md](references/story-structure.md)
- 角色圣经和逐页提示词填空：[references/templates.md](references/templates.md)
- 中文、拼音与英文版式：[references/layout-and-pinyin.md](references/layout-and-pinyin.md)
- 成书质检：[references/qa-checklist.md](references/qa-checklist.md)

## 1. 先做儿童安全检查

任何文案或提示词动笔前，先确认主题适合儿童启蒙插画。不合格就改题或拒绝，不要靠后期润色蒙混。

必须遵守：

- 只做健康、可共读的教育插画。冲突可以存在，但要用沟通、观察和温和行动解决，不能靠暴力、恐吓或羞辱。
- 不要恐怖、血腥、猎奇或突然惊吓的画面；夜景也要明亮、可解释，不画鬼怪、骷髅或威胁性怪物。
- 不要色情、性感化、成人恋爱或不当暴露。
- 不要教孩子可模仿的危险行为，例如拆电器、玩火、无看护戏水、独自使用刀具或锐器。厨房、海边、操场等生活场景里，危险动作须有成人在场，且不要把危险步骤画成可跟做的说明书。
- 不要使用已知的版权角色、影视角色、品牌标志或真实商标。角色必须是原创虚构形象。
- 默认不要把真实儿童照片或仿照片肖像当作成品插画。需要「像某位小朋友」时，也只提炼发型、服饰等约定特征，写成插画角色，并说明无法保证像本人。
- 科普只画孩子能看见的现象，不把内部结构或危险实验画成可操作步骤。

完整检查项见 [references/qa-checklist.md](references/qa-checklist.md)。

## 2. 定年龄、形式和学习目标

先问清目标年龄（约 3–12 岁）。没有年龄时先问，不要默认为「适合所有孩子」。页数、每页字数和角色数量都是创作起点，不是医学分级，也不能用来判断某个具体孩子的能力。

推荐形式只有两种：

- **故事绘本**：有可见的先后和因果，每页一个动作、发现或情绪变化。
- **单页互动 / 闪卡**：一页一个核心目标，例如指认、数数、字母或习惯卡片。不要暗中扩成故事，也不要把一组卡做成九宫格。

年龄与材料的对应、学习领域和学习目标，见 [references/age-and-materials.md](references/age-and-materials.md)。选定后写下一句话目标，例如：「给 5–6 岁共读，用海边回家的小事练习收妥湿雨靴，并认读「海、风、门、家」。」抽象主题必须先变成孩子看得见的动作和物件，不要把「勇气」「环保」直接写成说教句。

## 3. 写故事骨架和分页计划

不要一上来写一本散文再硬拆页。先压成五句骨架，再按页填计划表。

1. 主角是谁，最想做什么。
2. 这个小世界有什么具体限制或规则。
3. 主角第一次尝试时，哪里没做成或理解错了。
4. 主角靠自己的观察或行动发现关键，而不是听旁白讲道理。
5. 结尾有一个看得见的小变化，最好能和开头构图形成回声。

每页必须回答：上一页留下了什么状态，本页发生了哪个可见动作，主角知道了什么或情绪如何变化，下一页为什么会接着发生。删掉某一页如果故事不受影响，这页就要合并或重写。

先列正文里的可见名词和动作，再写画面；文字提到的物件，提示词里必须有对应视觉证据。画面里没有把握画准的细节，不要写进正文。这叫图文契约，格式见 [references/story-structure.md](references/story-structure.md)。

## 4. 写角色圣经，并在每页原样重复锚点

先写角色圣经和世界锚点，再写提示词。不要只写「同一个小朋友继续往前走」。

圣经至少锁住：名字、物种或年龄感、头身比与体型、脸和发型、固定服装与配色、固定配饰、表情基调、手部和肢体规则，以及「不能改变」的短列表。再设三类锚点：角色锚点、场景锚点、道具锚点。锚点要少而醒目，每页都写得进提示词。

低龄故事默认 1 个主角加 0–2 个配角。每个出场角色都要有自己的外观描述，不要用「家人」「远处的人影」代替。有人物互动时，写清可见的手、脚数量和左右手各拿什么；被遮挡的肢体也要说明。一次不要让角色同时做太多动作。

模板见 [references/templates.md](references/templates.md)。本技能的示例角色「阿潮」是虚构的海边小镇小朋友，只作填空示范；换成自己的角色时，只改圣经和锚点，不改流程。

## 5. 全书只锁一种画风

一本书只选一条主风格，线条、材质、色板和角色比例保持稳定。可以轮换满版场景页、留白动作页、物件特写页和回声页，但不能把水彩、剪纸、黏土和三维渲染混在同一本里。

选风和跨页锁定的方法、风格目录，见同仓库 `children-illustration-styles`。把该风格的 CORE 锚点整段贴进每一页提示词，本页只改动作、情绪、镜头和场景里的 FLEX 部分。

## 6. 按模型写逐页提示词，语法不要混用

同一套画面结构可以共用，参数写法必须按模型分开。未指定模型时，先问或同时给出 Midjourney、Stable Diffusion、自然语言三套，并标明模型。多组提示词必须各自写全，不要写「沿用上方」。

| 模型 | 怎么写约束 | 不要混入 |
| --- | --- | --- |
| Midjourney / Niji | 正文用逗号或自然语言，参数放末尾，例如 `--ar 3:4 --stylize 80 --v 6`。排除用 `--no extra fingers, text, watermark, logo`。 | 不要写 `(hand:1.4)`，也不要另起一行 `Negative prompt:`。 |
| Stable Diffusion / SDXL | 强调用 `(word:1.2)`，减弱用 `(word:0.7)`。负面词必须单独放在 Negative prompt 里。画幅用界面宽高。 | 不要写 `--ar`、`--stylize`、`--v`、`--no`。 |
| Flux / GPT Image / DALL·E / Nano Banana Pro | 用完整句子写清要什么、不要什么。画幅写成 “Create a 3:4 image”，禁止项写成 “Do not include…”。 | 不要把 `--ar 16:9` 或 `(watercolor:1.3)` 塞进自然语言段。 |

还要记住：词序会改画面，角色和本页动作放前面；锁材质写清楚画在什么纸、用什么颜料；锁画风写清楚一种材料体系。

每页提示词按这个顺序组装：绘本页类型和画幅 → 完整角色锚点 → 本页唯一动作、场景、情绪和镜头 → 图文契约（正文里的可见证据） → 肢体约束 → 风格 CORE 锚点 → 连续性要求 → 禁止项。内页默认要求画面内无正文，文字留给后期排版；封面短标题如需进画，必须逐字写出并在生成后核对。完整填空见 [references/templates.md](references/templates.md)。

出图顺序：先做角色基准页或封面校准，再做前 2–3 页检查一致性，稳定后才继续后面的页。不要把多页拼成一张图。旧图不要覆盖，返工另存为 `-v2`。

## 7. 安排中文、拼音和英文

中文正文先定稿，再标拼音、再写英文。拼音保留声调，按句意标注多音字。英文写成可朗读的短句，不要机械直译，也不要添出画面里没有的物件。同一本书里的角色译名保持固定。

内页默认用后期排版：拼音在上、中文居中、英文在下；拼音与汉字按字格对齐，英文整句排，不和汉字硬性逐词对齐。文字不要压住脸、手和关键道具。细则见 [references/layout-and-pinyin.md](references/layout-and-pinyin.md)。

## 8. 质检后再交付

交付前按 [references/qa-checklist.md](references/qa-checklist.md) 检查故事因果、适龄与安全、跨页一致性、图文契约、肢体、拼音和排版。没有实际看到的图，不能写成「已通过」。不合格时先判断是故事、文案、提示词、出图还是排版问题，再做最小修复，不要整本推倒。

## 9. 输出要求

规划阶段先给出：书名或主题、年龄、形式（故事或闪卡）、页数、一句话学习目标、主角锚点、选用画风，以及按页排列的「画面 / 拼音 / 中文 / 英文」。生成阶段再给出按模型区分的完整提示词，并标明哪些页需要复查。

不要把真实公司名、地址、密钥或未公开项目名写进提示词或示例。
